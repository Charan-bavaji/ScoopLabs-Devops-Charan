# File Handling - L1

## Description
Reading from and writing to the file system using Python.

## Concept Task
**Difference between "w" mode and "a" mode:**
- **"w" (write) mode** — opens the file for writing. If the file already
  contains data, it is erased first, then the new content is written. If
  the file doesn't exist, it is created.
- **"a" (append) mode** — opens the file for writing but adds new content
  to the end of the existing content, without deleting what's already
  there. If the file doesn't exist, it is created.

## Hands-on Task
A Python script (`file_handling.py`) that:
- Creates a file named `system_info.txt`
- Writes the text `"System check passed"` into it
- Reads the file back and prints its contents to the console

## How to Run
```bash
python3 file_handling.py
```

## Sample Output
```
Contents of system_info.txt :
System check passed
```

## Code
 
```python
"""
Assignment: File Handling - L1
Task: Create a file, write text into it, then read and print its contents.
"""
 
filename = "system_info.txt"
 
# Write to the file (creates it if it doesn't exist, overwrites if it does)
with open(filename, "w") as f:
    f.write("System check passed")
 
# Read the file and print its contents
with open(filename, "r") as f:
    contents = f.read()
 
print("Contents of", filename, ":")
print(contents)
```
